# Parse WhatsApp Chat Export

This example demonstrates how to parse a simulated WhatsApp chat export text file using Python. It extracts date, time, sender, and message content from each line, handling common variations like multi-line messages and system notifications. The output is a structured JSON representation of the chat history.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
